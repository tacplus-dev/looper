# Security job's clippy fails every gateway build: built/ drops the generated non-.rs files src/registry.rs include_str!s (3 compile errors)

## What fails

Every full-gates build of tacplus-dev/gateway fails in its security job with:

```
verdict: failure: security: clippy: exited 101: error: could not compile `gateway` (bin "gateway") due to 3 previous errors
```

The latest is build pipeline 3067906317 (gateway 974e71c). Its gates passed, and the commit status is set by `security-failed` (#144, #148). Builds 3064864987, 3065552311 and 3065826409 failed the same way. This blocks tacplus-dev/gateway#35, #34 and #29, and gateway's v0.1.2.

## Why

`looper-build`'s `built()` keeps only some of the gates' untracked files for the security job: `.rs`, `.go` and other sources, manifests, bytecode and release jars. The security job lays them over its own checkout. Gateway's `src/registry.rs` compiles in three files that tacplus generates in its output-dir, `target/generated-sources/model`:

```rust
const REGISTRY_JSON: &str = include_str!("../target/generated-sources/model/registry.json");
... include_str!("../target/generated-sources/model/registry.schema.json");
const AGENT_MD: &str = include_str!("../target/generated-sources/model/AGENT.md");
```

None of the three matches `built()`'s filter (`.json` is kept only as `package(-lock).json`, `.md` not at all). So the security job's tree has the generated crates but not these files, and clippy's compile of bin `gateway` stops on exactly 3 errors. The gates' own `cargo` sees the files and passes. The nightly scan reproduced the same clippy run with the generated tree complete and got no compile error (gateway#35).

## Fix recommended

`built()` keeps every untracked file under the root `tacplus.yaml`'s output-dir (looper-scan already knows that tree, #108), not just source extensions. It still excludes `target/(debug|release|deps|build)/` and dependency trees. Alternatively, keep the non-source files a crate can `include_str!`/`include_bytes!` (`.json`, `.md`, `.yaml`, `.proto`, `.bin`).

## Acceptance criteria

- A test in `tests/looper-build.test.sh`: a tacplus project whose untracked output-dir holds a `.json` and a `.md` that a `.rs` file `include_str!`s ends up with both in `built/`.
- A full-gates build of gateway 974e71c (or its successor on main) has a green security job, with no `clippy:` line under Problems.
